## Known gaps

- **The running preview server still has the old lib/bot.js loaded.** It was started before the backend change, and I was told not to restart servers. So in the preview, Save drops `project` and `options` (seen: after saving, houses came back with no project and 0 options). The UI was verified with unsaved state, plus the offline `cleanSettings` round trip above. After a preview restart, Save → reload should keep them; this is not yet confirmed in the browser.
- The `preview.mjs` changes (`facebookPublic: false`, more useful fake reply) also take effect only after a restart. The missing `facebookPublic` is already treated as false, so the banner is right either way.
- The draft mark on starters isn't saved: it disappears after a reload, though the text stays.
- The paste parser only reads labelled amounts. "Marigold Model | Price package | Bank Loan | 5,120,000" has no "Price" label, so its price is left empty, on purpose. A text that names several financing types leaves the type for the user to pick.
- Not done: the "Compare with what's saved" toggle from the audit's B6 idea (not in the approved list). The 760-1180px tablet layout was only checked in code. Real LLM replies were not checked (the preview echoes).
